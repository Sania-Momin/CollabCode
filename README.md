# Real-Time Code Editor with Collaborative Platform

## Overview

The **Real-Time Code Editor with Collaborative Platform** is a web-based application that enables multiple users to collaborate on code in real time. It provides an interactive coding environment with live editing, communication tools, AI assistance, and learning support.

---

## Key Features

* **Authentication:** Home, Login, and Signup pages
* **Room Management:**

  * Create a room with a unique Room ID
  * Join an existing room using the Room ID
* **Real-Time Collaboration:**

  * Live code synchronization
  * Display of active users in the room
* **Code Editor:**

  * Monaco Editor with syntax highlighting
  * Multiple programming languages
  * Theme selector
* **Communication:**

  * Live chat
  * Voice messaging
* **Personal Features:**

  * Personal AI Assistant
  * Learn Language module (auto-switches based on selected language, e.g., Learn C)
  * Theme selection for editor customization
* **Code Execution:**

  * Input/Output section for running code
* **Collaborative File Manager:**

  * Shared file creation and management within rooms

---

## Deployment

* **Frontend:** Deployed as a static site on Render
* **Backend:** Deployed as a web service on Render

---

## Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Real-Time:** WebSockets / Socket.IO
* **Editor:** Monaco Editor
* **Deployment:** Render
